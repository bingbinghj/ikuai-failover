# ikuai-failover

使用 Rust 后端和 Vue 3 控制台管理爱快物理出口故障转移，主线路恢复并满足条件后自动回切。主线路、备用线路和要保留的默认 WAN 从爱快实际接口中选择。

- 爱快连接通过账号密码建立 Web 会话，IPv4 与 IPv6 共用连接凭据。
- 控制台使用独立登录账号；记住密码后默认保持登录 30 天，并在本浏览器加密保存用于回填的密码，过期后返回登录页。账号或密码未填写时，启动时自动生成并保存到配置文件。
- 空配置目录首次启动自动生成模板；爱快账号密码可以留空，之后通过控制台或本地配置填写。
- 可视化配置自动读取爱快接口、分流规则和 IPv6 实例，使用下拉选择；有运营商标识时一并显示，没有时显示接口名。
- 防回环、运营商分流和域名分流规则从爱快选择，内部 ID 和规则名称自动保存，无需手填；默认只读生成计划。
- IPv6 切换分别确认出口地址、PD 与 LAN 前缀；异常独立报告，IPv4 故障转移继续运行。
- 通知按需添加，支持 MoviePilot v3 的 14 类渠道及企业微信机器人，包含线路、地址、切换回切、配置保存、策略异常和服务事件。
- 页面按 MoviePilot 的主题、MDI 图标、卡片和表单布局重构，主体铺满侧栏后的可用空间；支持浅色、深色和跟随系统。登录背景使用 Bing 每日壁纸，头像菜单只显示重启和退出。
- 刷新页面保留当前页面及设置、日志标签；账号菜单采用紧凑操作列表。
- 日志中心默认实时日志，支持 ALL、DEBUG、INFO、WARNING、ERROR、搜索、暂停和历史文件选择；历史直接显示文件名，单滚动正文可完整查看 600 条记录，单份最多 5 MiB，总共保留 10 份。
- 总览卡片一一对应独立简洁弹窗：出口线路只显示线路、策略只显示规则、IPv6 只显示 IPv6；当前出口可选择主线路、备用线路或恢复自动切换。
- 通知渠道采用 MoviePilot v3 的字段与默认发送格式（企业微信群机器人独立配置），只显示当前渠道支持的格式。Telegram 支持 MarkdownV2/HTML/Text，Discord 默认 Embed，飞书默认 Markdown 交互卡片，企业微信应用增加无封面、无跳转 News。模板测试可临时选择发送格式，不保存草稿；切换消息显示前后线路、运营商和 IP，缺失数据省略，时间使用北京时间。
- GitHub Actions 构建 Docker 镜像，构建成功后直接发布到 Packages。

镜像：`ghcr.io/bingbinghj/ikuai-failover:latest`。容器管理端口为 TCP `19002`，部署参数见 [故障转移服务](docs/failover.md)，通知参数见 [通知配置](docs/notifications.md)，默认格式及源码依据见 [MP通知格式对照](docs/MP通知格式对照.md)，规则选择见 [分流配置指南](docs/routing-review.md)。

公开模板使用通用示例；实际连接信息和选择结果保存在部署目录的 `data/config.yml`，该文件保留在本地。配置页面仅提供可视化表单，保存后按提示重启服务。

| Compose 环境变量 | 用途 | 留空时 |
| --- | --- | --- |
| `IKUAI_FAILOVER_USERNAME`、`IKUAI_FAILOVER_PASSWORD` | 爱快路由器管理账号密码，用于连接爱快 | 使用配置文件的 `ikuai.username/password`；仍为空时等待配置 |
| `IKB_WEBUI_USER`、`IKB_WEBUI_PASS` | 本服务网页登录账号密码 | 使用 `webui.user/pass`；缺失字段自动随机生成并保存 |

非空环境变量覆盖对应配置字段。希望通过网页维护爱快连接信息时，保持对应环境变量为空。修改 Compose 环境变量后需重新创建容器；网页保存配置后可按提示重启服务。
